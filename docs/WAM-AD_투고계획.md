## 2. 논문 설계

**제목 후보**
- *Imagine Once, Act Fast: Lightweight Action Readout from a Frozen Driving World-Action Model*
- *One Imagination Step Is Enough: Replacing Iterative Action Denoising in a Driving World-Action Model*

**주장 (방어 가능한 범위만)**
1. 고정 WAM의 **첫 상상 패스** 표현 + 작은 head로, 반복 action 생성의 평균 예측 수준 정확도를 낸다. 결정 지연은 B10의 1/12, 품질을 맞춘 최소 단계 기준(B\*)의 0.16배다. PhysicalAI-AV 공식 test 1k에서 사전등록 기준을 통과했다.
2. **상상이 핵심이다.** first ≫ current(ADE −0.11m)이고 terminal ≈ first다. 안내 문장을 빼도 유지된다. NAVSIM에서도 first − current = +3.3 PDMS다.
3. 기억과 언어 안내도 readout에 기여한다(각 0.02–0.045m). 상상 효과보다는 작다.
4. **평가 방법론:** 공식 single-seed 평가는 seed에 민감하다(B10 ADE 0.82–0.93). 결정적 readout과 비교할 때는 다표본 평균 대조가 필요하다.

쓰지 않는 주장: "B10보다 정확하다"(결정성 효과가 섞임).

**분량 배분 (참고문헌 포함 8쪽)**

| 절 | 쪽 | 내용 |
|---|---:|---|
| 초록 + 1 서론 | 1.0 | 문제(action 병목), 질문, 기여 3–4개. 그림 1(개요) |
